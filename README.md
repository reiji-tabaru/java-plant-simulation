# Java Plant Simulation

A Java application that simulates different plant species
and their reactions to daily radiation.

## Project Structure

- `FirstAssignment.java` - Main entry point of the program.
- `Plant.java` - Abstract/base class for plants.
- `Puffs.java` - Represents the Puffs plant type.
- `Parabush.java` - Represents the Parabush plant type.
- `Deltatree.java` - Represents the Deltatree plant type.
- `Radiation.java` - Defines the radiation types used in the simulation.
- `Simulation.java` - Handles the daily simulation logic.
  
## Features
- Object-oriented programming
- Inheritance and polymorphism
- File input
- Daily simulation logic
